# Super Sam

Super Sam ist ein kleines 2D-Plattformspiel, das mit Godot 4 entwickelt wurde.

Das Projekt entstand ursprünglich im Rahmen des GameDev.tv-Kurses *Martian Mike* und wurde anschließend erweitert und individuell angepasst. Dazu gehören zusätzliche Level, Spielelemente, Benutzeroberfläche, Sounds und weitere eigene Ergänzungen.

## Funktionen

- mehrere spielbare Level
- sammelbare Münzen
- Hindernisse und Gefahren
- Soundeffekte und Hintergrundmusik
- eigene Benutzeroberfläche und Credits
- zusätzliche eigene Spielelemente und Szenen

## Technik

- Godot 4
- GDScript

## Lokal starten

Das Projekt in Godot 4 öffnen und direkt über den Editor starten.

# Super Sam

Super Sam is a small 2D platformer built with Godot 4.

The project started as part of the GameDev.tv *Martian Mike* course and was extended and customized with additional levels, gameplay elements, UI, sounds and other features.

## Features

- multiple playable levels
- collectible coins
- obstacles and hazards
- sound effects and background music
- custom UI and credits
- additional custom game elements and scenes

## Tech

- Godot 4
- GDScript

## Run locally

Open the project in Godot 4 and run it from the editor.
